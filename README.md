# 121Lab2-RandomNum

##Steps to create num game
* Import i/o

* Ask for user name
  * Create a string array to store name
  * print statement that welcomes user and asks to play game

* Create Random Number Generator
  * generate a number from 1 to 100
  * store generated number in an int variable

* Ask user for a number
  * Compare user number to generated number
  * Gives user feedback (if the number is too high or too low)
  * Loops WHILE the user hasn't guessed the correct number
  * Tally the amount of turns the user has taken
  * Ends loop when the user has correctly guessed the number
  * Congratulates user when correct
  * Returns 0 error code
